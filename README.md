# BorderPlates

**Version:** 1.0.0  
**Game:** World of Warcraft 3.3.5a — Wrath of the Lich King  
**Interface:** 30300

BorderPlates is a custom unit-frame addon for World of Warcraft 3.3.5a. It provides a distinctive metallic design for player, target, pet, party, and raid frames.

## Features

- Custom player, target, pet, party, and raid frames.
- Health and resource bars, unit names, and levels.
- Player and target cast bars.
- Frame positioning and display commands.
- Raid frame test mode.

## Installation

1. Close World of Warcraft.
2. Extract the downloaded ZIP archive.
3. Copy the `BorderPlates` folder into `World of Warcraft/Interface/AddOns/`.
4. Enable **Border Plates** on the character selection screen, then enter the game.

Make sure the files are directly inside `Interface/AddOns/BorderPlates/` (not inside a second nested `BorderPlates` folder).

## Commands

Type `/bp` in chat for the in-game command list. Available commands include:

| Command | Purpose |
| --- | --- |
| `/bp` | Show command help. |
| `/bp show` / `/bp hide` | Show or hide the player frame. |
| `/bp lock` / `/bp unlock` | Lock or unlock frame movement. |
| `/bp reset` | Reset settings. |
| `/bp location original` / `/bp location center` | Choose the frame location preset. |
| `/bp text num` / `/bp text pct` / `/bp text both` | Change value display format. |
| `/bp zoom 0.7` | Set frame zoom (0 to 1). |
| `/bp pos 0 0 0` | Set frame position offsets. |
| `/bp raidtest` | Toggle simulated raid frames. |

## Compatibility

Built for the **3.3.5a** client (interface 30300). Compatibility with modern Retail or Classic clients is not claimed.
