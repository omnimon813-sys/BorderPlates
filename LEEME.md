# BorderPlates

**Versión:** 1.0.0  
**Juego:** World of Warcraft 3.3.5a — Wrath of the Lich King  
**Interfaz:** 30300

BorderPlates es un addon de marcos de unidad personalizados para World of Warcraft 3.3.5a. Ofrece un diseño metálico distintivo para los marcos de jugador, objetivo, mascota, grupo y banda.

## Características

- Marcos personalizados de jugador, objetivo, mascota, grupo y banda.
- Barras de vida y recursos, nombres y niveles.
- Barras de lanzamiento del jugador y del objetivo.
- Comandos para ajustar la posición y visibilidad del marco.
- Modo de prueba de marcos de banda.

## Instalación

1. Cierra World of Warcraft.
2. Extrae el archivo ZIP descargado.
3. Copia la carpeta `BorderPlates` en `World of Warcraft/Interface/AddOns/`.
4. Activa **Border Plates** desde la pantalla de selección de personajes y entra al juego.

Comprueba que los archivos estén directamente en `Interface/AddOns/BorderPlates/`, sin una segunda carpeta `BorderPlates` dentro.

## Comandos

Escribe `/bp` en el chat para consultar la ayuda. Entre los comandos disponibles están:

| Comando | Función |
| --- | --- |
| `/bp` | Mostrar la ayuda. |
| `/bp show` / `/bp hide` | Mostrar u ocultar el marco del jugador. |
| `/bp lock` / `/bp unlock` | Bloquear o desbloquear el movimiento del marco. |
| `/bp reset` | Restablecer la configuración. |
| `/bp location original` / `/bp location center` | Elegir una ubicación predefinida. |
| `/bp text num` / `/bp text pct` / `/bp text both` | Cambiar el formato de los valores. |
| `/bp zoom 0.7` | Ajustar la escala del marco (de 0 a 1). |
| `/bp pos 0 0 0` | Ajustar los desplazamientos de posición. |
| `/bp raidtest` | Activar o desactivar marcos simulados de banda. |

## Compatibilidad

Diseñado para el cliente **3.3.5a** (interfaz 30300). No se garantiza compatibilidad con Retail ni con las versiones modernas de Classic.
